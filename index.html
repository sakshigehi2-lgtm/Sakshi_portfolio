Academic Mini Project • Team Project

QR Code Based Smart Attendance Management System

R.C. Patel Institute of Technology, Shirpur

A modern, web-based system engineered to simplify classroom attendance using dynamic QR codes. Designed to eliminate manual paper roll calls, minimize proxy attendance, and streamline teacher-student verification in real time.

Key Architecture & Contributions:

  • Student Authentication: Secure roll-number credential validation and session verification.
  • Dynamic QR Generation: Time-sensitive encrypted QR tokens expiring after a countdown to prevent proxy sharing.
  • Backend APIs & Database Integration: Real-time storage of present/absent logs with duplicate entry prevention.
  • Collaborative Engineering: Collaborating with a team to build, test, and integrate frontend & backend modules.
Dynamic QR Engine Java / JS Database APIs HTML5 / CSS3 Authentication
